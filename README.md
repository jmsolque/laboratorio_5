# laboratorio_5
En este laboratorio se tiene 3 estructuras de datos, las cuales son:

## Arreglo Dinámico
Este consiste en crear un arreglo, agregar elementos a este, eliminar elementos, obtener el elemento por índice e imprimir el arreglo.

## Lista enlazada
Esta estructura de datos, consiste en insertar un nodo al inicio, un nodo al final o insertar un nodo en una posición específica. También se puede buscar un elemento a través de los nodos enlazados y por último, se puede imprimir la lista hacia adelante.

## Stack
En esta estructura de datos, se puede agregar un elemento en la parte superior de la pila, también se puede eliminar y devolver el elemento en la parte superior de la pila. Además se puede devolver un elemento a la parte superior de la pila sin la necesidad de eliminarlo y por último se puede verificar si la pila está vacía.

## ¿Cómo compilar?
Para compilar este proyecto es muy sencillo, solamente se debe de clonar este repositorio en una computadora con Linux, a través de la terminal acceder al directorio "laboratorio_5" el cual es el que se clonó; esto mediante "cd laboratorio_5". Una vez dentro escribe en la terminal la palabra "make" y  vas a obtener el ejecutable, ya que se contiene un Makefile, que compila todo a través de comandos, los cuales también se puede hacer a mano, utilizando "gcc -Wall -Wextra -Iinclude", el -Iinclude manda a buscar los header files al directorio include, por lo que si tu directorio donde se encuentran los headers files no es include debes de colocar "-Inombre_del_directorio".

## Pasos para ejecutar
Luego de escribir la palabra make en la terminal, en este caso el programa se llamará "estructuras_datos", por lo que para ejecutar solamente basta con colocar "./estructuras_datos" y ya ejecutarás el proyecto.
